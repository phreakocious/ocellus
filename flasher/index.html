ocellus firmware installer

Flashes the eye directly from this page — no software to install.

  1. macOS only: install the CH34x USB driver (unzip, run it, approve in System Settings → Privacy & Security, reboot if asked). Windows and Linux need no driver.
  2. Plug the board into USB. Use Chrome, Edge, or Firefox 151+ on a computer (Safari won't work).
  3. Click Install below, pick the board's serial port, and let it run.
Install This browser has no Web Serial — use Chrome, Edge, or Firefox 151+ on a computer. (Linux distros often ship an older Firefox ESR.) This page must be served over HTTPS.

About the pictures and GIFs on your eye

Slideshow images and animated GIFs live in a separate area of the chip from the firmware, so re-flashing from this page normally leaves them alone — unless you tick “erase device”, which wipes everything and gives you an eye with no pictures on it.

There is about 13.9 MB of space, shared between images and GIFs. A typical GIF is 0.1–1.5 MB, so that is roughly 15–20 of them. The config page lists what is on the device and how much room is left, and lets you delete or replace any clip by name.

Uploading a GIF through the config page takes about a minute per clip — it goes over the same slow serial link as the settings. That is fine for swapping one or two. Loading a whole set is much faster from a terminal (tools/flash.py <target> --gifs SET, ~150 s for any number of clips).

No serial port in the picker? On macOS, finish step 1's driver. If it still won't appear or won't connect, hold BOOT, tap RESET, release BOOT, then click Install again.

Linux: give yourself access to the serial port — sudo usermod -aG dialout $USER (uucp on Arch), then log out and back in.
