ocellus firmware installer

Flashes the eye directly from this page — no software to install.

  1. One-time: install the CH343 USB driver, then reboot if it asks.
  2. Plug the board into USB. Use Chrome or Edge (easiest — Safari won't work).
  3. Click Install below, pick the board's COM port, and let it run.
Open this page in Chrome or Edge on a computer. This page must be served over HTTPS.

If no port appears, the driver isn't installed yet (step 1).
If it appears but won't connect, hold BOOT, tap RESET, release BOOT, then Install again.
