ocellus Config — Help

  • Requires Chrome/Edge, served from localhost or https (not file://). Close any other tab holding the serial port.
  • Connect → pick the device's USB serial port; the form unlocks and loads current settings.
  • Live preview jumps the running animation immediately. It is not saved — a power-cycle returns to your Startup setting.
  • Save to device persists everything below across reboots. Reload re-reads the device.
  • Favorites: the device button single-clicks through these; none checked = all play. Palettes: none enabled = Rainbow; multiple rotate on the timer.

Device button

  • Single-click — next favorite animation
  • Double-click — jitter (eye modes)
  • Triple-click — debug screens (sensor / audio / waterfall)
  • Quadruple-click — jump into / cycle the effects
  • Long-press — sleep / power off (click to wake)
